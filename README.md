🫧 **I built [OrbFlow](https://github.com/cascadingGeek/OrbFlow)**

A bubble chart library for the web where the bubbles act like real soap bubbles. They rise in when the chart scrolls into view, float, push each other apart, and pop when you tap them. Bubble size follows your data, so it works for anything shaped like "how much of each thing": tickets by tag, revenue by product, votes, or market moves.

- Zero runtime dependencies, about 15 kB gzipped, drawn on canvas
- Plain JavaScript or React 18/19 (Next.js and server rendering included), with TypeScript types
- Accessible: keyboard navigation, screen reader support, and respect for "reduce motion"
- Tested end to end: unit, integration, real browser, and install checks on every release

```bash
npm i orbflow@beta
```

It's in public beta now. Try it, break it, and [tell me what confused you](https://github.com/cascadingGeek/OrbFlow/issues). If OrbFlow saves you time, you can [sponsor my work](https://github.com/sponsors/cascadingGeek) ❤️
